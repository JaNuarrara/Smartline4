Connection Requirements / Kenapa micro:bit Tidak Konek?

  • HTTPS / Localhost: Web Bluetooth hanya berfungsi jika website dibuka melalui protokol aman https:// atau via localhost (Live Server).
  • Browser Support: Gunakan browser berbasis Chromium seperti Google Chrome, Microsoft Edge, atau Opera (Safari dan Firefox tidak mendukung Web Bluetooth secara bawaan).
  • Bluetooth Terbuka: Pastikan Bluetooth di komputer/HP Anda sudah dinyalakan dan tidak sedang tersambung ke aplikasi lain.
  • Flash Firmware: Pastikan micro:bit sudah di-flash dengan kode program yang mengaktifkan Bluetooth Service (UART Service) dengan mode "No Bonding" / pasangkan tanpa pin.
